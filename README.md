## About Me

<img align="right" width="240" src="https://github-readme-stats.vercel.app/api/top-langs/?username=challaajay777&layout=donut-vertical&theme=github_dark&hide_border=true&langs_count=7" alt="Most used languages" />

Hey! I'm **Ajay** — a student, C++ programmer, competitive programmer, and software builder.

My interests sit at the intersection of **algorithmic problem-solving** and **practical engineering**. I enjoy the discipline of competitive programming: reading a problem carefully, finding the right model, choosing an efficient algorithm, proving it works, and implementing it cleanly.

Outside contests, I like building complete tools and applications — from a native C++ contest workstation to local-first desktop software and cross-platform apps.

### A few things about me

- 🧠 **Problem solving:** I practise on Codeforces, AtCoder, CodeChef, and LeetCode.
- 💻 **Main language:** C++ — with a growing interest in systems programming and Rust.
- 🏁 **Contest mindset:** learn the idea, analyse complexity, implement, test edge cases, and review.
- 🛠️ **Builder mindset:** I enjoy working on products with real workflows, architecture, and usable interfaces.
- 🎥 **Creator:** I publish coding and competitive-programming content on YouTube.
- 🌱 **Always learning:** algorithms, data structures, number theory, systems, and software design.

<br clear="right"/>

### The way I like to work

```text
  understand  ->  model the problem
       |                 |
       v                 v
  design algo   ->  analyse complexity
       |                 |
       v                 v
  implement     ->  test edge cases
       |                 |
       +------->  improve & ship
```

**A cross-platform competitive-programming workstation and contest tracker.**

<a href="https://github.com/challaajay777/contestpulse">
  <img src="https://img.shields.io/badge/VIEW%20PROJECT-ContestPulse-1F6FEB?style=for-the-badge&logo=github" alt="View ContestPulse" />

ContestPulse is designed to keep contest schedules, past contests, and platform information in one fast, keyboard-friendly workspace.

**Highlights**

- Native **C++20** core and a developer-focused dark interface.
- Windows desktop workstation with a floating contest mini-widget.
- Linux and macOS terminal workstation.
- CLI with live watch mode, filtering, history, syncing, and briefings.
- SQLite-backed contest history.
- Scheduled background synchronisation.
- Vim-inspired command bar and keyboard-first navigation.
- Project description lists 31 platform feeds, including Codeforces, AtCoder, LeetCode, and CodeChef.
- Free and open source, with zero telemetry.

**Technology:** `C++20` · `CMake` · `SQLite` · `Win32` · `CLI` · `REST APIs`

### 02 — ChangeRadar

**Universal file intelligence, version history, and recovery.**

<a href="https://github.com/challaajay777/ChangeRadar">
  <img src="https://img.shields.io/badge/VIEW%20PROJECT-ChangeRadar-1F6FEB?style=for-the-badge&logo=github" alt="View ChangeRadar" />
</a>
<img src="https://img.shields.io/badge/RUST-SYSTEMS-DEA584?style=for-the-badge&logo=rust&logoColor=black" alt="Rust" />
<img src="https://img.shields.io/badge/ARCHITECTURE-LOCAL--FIRST-238636?style=for-the-badge" alt="Local first" />

ChangeRadar is a local-first, offline-first file intelligence platform. It watches selected folders, tracks file history, compares revisions, and provides a safety-focused recovery workflow.

**Highlights**

- Cross-platform filesystem monitoring.
- Content-addressed storage with BLAKE3 hashing and Zstandard compression.
- SQLite metadata storage.
- Change intelligence and a Radar Score.
- Comparison support for text, code, JSON, CSV, images, PDFs, and binary data.
- Safety-first recovery with conflict checks and backups.
- Desktop app, CLI, and background daemon.
- Local developer API and a permission-bounded plugin architecture.
- Zero-telemetry, local-first design.

**Technology:** `Rust` · `Tauri 2` · `React` · `TypeScript` · `SQLite` · `BLAKE3` · `Zstandard`
